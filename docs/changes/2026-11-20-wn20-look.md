# WN-20 Windows password rotation: the new look and questions

- Each account is asked: random, set one (typed twice, hidden), keep, all the rest; then "Apply these changes?" (and the protected-list question).  -Users/-Exclude/-Passwords/-Apply/-NoProtected answer them; -Batch takes the defaults.  New -Batch, -NoColor.
- The look of LX-20; results in passwords-N with output.txt; accounts.txt, passwords.txt and pending-password.txt instead of CSV; -Passwords takes "account password" lines (old comma lines still work).
- Library: Read-CcSecret (hidden typing; never logged).
