# WN-44 Windows change watch, new

- Fills the planned WN-44 (Windows alerts). A baseline, then one alert per change, worst first, once or every N seconds: accounts, admin groups (domain ones on a DC), services, a running service stopped, tasks, Run keys, listeners, shares, firewall / Defender / WDigest / sticky keys turned off, WMI subscriptions, debuggers, the hosts file, IIS pages, and from the event logs a cleared log, a service installed, a task or account created, a group member added, Remote Desktop logons from new addresses. Read-only. The Windows twin of LX-40.
