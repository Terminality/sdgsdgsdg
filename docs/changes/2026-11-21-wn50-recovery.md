# WN-50 Windows service recovery, new

- Why a scored Windows service is down and the fix: IIS (sites and app pools), Apache, nginx, SQL Server, MySQL, AD, DNS, RDP, SMB, the event log, the protected list. Checks running, disabled, its program, its port (or another program on it), the answer, an inbound block rule, restart-on-crash. Each fix asked (yes/no), then checked again. `-Watch` with `-AutoRestart`. No revert timer; revert.ps1 undoes. The Windows twin of SV-50.
- lib.ps1: `Write-CcRevert` writes a run's revert.ps1 without a timer (Start-CcTimer uses it).
