# SV-30 on Alpine (OpenRC)

- Apache on Alpine: the drop-in goes in /etc/apache2/conf.d (there is no
  conf-enabled), so versions are hidden and TRACE and listings are off there too.
- PHP in /etc/phpNN/php.ini (Alpine) is found; expose_php is turned off and
  php-fpmNN (or apache2) is restarted.
- OpenRC: "is it enabled" is read from `rc-update show`, so a service that is
  stopped and not in a runlevel is "already ok", and the undo only adds it back
  to a runlevel if it was in one.
