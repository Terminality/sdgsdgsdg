# WN-16 Windows web shell hunter, new

- Reads every IIS site folder (applicationHost.config), C:\inetpub\wwwroot, XAMPP and WAMP for web shells in ASP.NET, classic ASP, PHP and JSP, code in upload folders or hidden in images, and a web.config that makes images run as code. HIGH offered for quarantine (default yes), MED kept by default, LOW (changed lately) listed. The site must still load after quarantining or the files go back at once; revert timer. The Windows twin of SV-16.
